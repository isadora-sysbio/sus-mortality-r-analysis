# Module 2 · Lesson 2 · Activity 6

## Complete graph contextualization

## Goal

Create a graph that can be interpreted **without needing the surrounding
notebook or verbal explanation**.

The Fiocruz activity defines a good graph as self-explanatory and highlights
five core elements:

- clear title;
- informative subtitle;
- axis labels with units;
- clear legend when applicable;
- data source in the caption.

## Example

The activity uses birth-weight data for 20 newborns and constructs a histogram
with:

- eight bins;
- a dashed mean reference line;
- an annotation showing the mean;
- a clear title and subtitle;
- grams on the x-axis;
- frequency on the y-axis;
- a source note in the caption.

## Why context matters

A figure may leave the original script, notebook, slide deck, or article.

Without context, a reader may not know:

- what variable is being shown;
- what the units are;
- what population/sample is represented;
- what a reference line means;
- where the data came from.

A self-explanatory figure reduces this ambiguity.

## Contextualization checklist

Before exporting a figure, ask:

1. Does the title state what is being shown?
2. Does the subtitle add useful context rather than repeat the title?
3. Are axis labels explicit?
4. Are physical/clinical units included?
5. Are legends necessary and understandable?
6. Are annotations interpretable?
7. Is the data source documented?

## Research lens

In health research, units are especially important. A label such as
`Birth weight` is incomplete if the reader cannot tell whether the values are
in grams or kilograms.

Likewise, a reference line should never appear unexplained.
