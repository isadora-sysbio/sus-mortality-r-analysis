# Methods notes

Welch's t test compares independent groups without assuming equal variance. ANOVA is followed by multiplicity-adjusted Tukey comparisons. Logistic coefficients are odds ratios with confidence intervals, not risk ratios. Residual plots support—but cannot prove—linear-model assumptions. Random intercepts represent hospital clustering. ARIMA forecasts are conditional on the simulated process. Survival workflows allow censoring; proportional hazards are checked in the oncology case.

All case-study data are synthetic except R's built-in `anscombe` dataset and the optional local SIM input. Results demonstrate methods and are not estimates for real populations, patients, treatments, or services. Association is not interpreted as causation.
