# Analysis Notes

## Scope

This project provides a descriptive analysis of mortality records.

The results describe the records contained in the dataset and should not
automatically be interpreted as population mortality rates.

## Epidemiological distinction

Counts of deaths are not equivalent to mortality rates.

Population-level comparisons require suitable denominators such as
population size stratified by age, sex, location and time.

## Possible extensions

Future analyses could include:

- cause-specific mortality
- age-standardized mortality rates
- multi-year temporal trends
- municipality-level comparisons
- population-adjusted rates
- confidence intervals
- statistical inference
